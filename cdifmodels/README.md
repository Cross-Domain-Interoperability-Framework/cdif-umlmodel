# cdifmodels

The file cdifmodels.xmi is the Canonical XMI file of the CDIF UML model.

No changes should be made to the model at this time. It is being generated. Any changes will be made during the generation process, not in Enterprise Architect.

It can be imported into Enterprise Architect. Instructions:
- New Project ...
- Publish / Import / XMI File ...
- ... Import / Yes 
- ... Close the window after the Progress shows "Import Complete"
